# Samra MERN Ecommerce (Frontend)

This project is a React application.

## Quick Preview (Local)

Use these commands in the project root:

```bash
npm install
npm start
```

Then open:

- Main app: [http://localhost:3000](http://localhost:3000)
- SaaS Studio page (new): [http://localhost:3000/saas-studio](http://localhost:3000/saas-studio)

## Available Scripts

### `npm start`
Runs the app in development mode.

### `npm test`
Runs the test runner in interactive watch mode.

### `npm run build`
Builds the app for production to the `build` folder.

### `npm run eject`
One-way operation to expose build tooling config.
